## GitHub Pages 配置

[打开本仓库的 GitHub Pages 设置页面](https://github.com/vito-epiphany/zhixingjian/settings/pages)

部署设置：在 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`，然后保存。

> 本仓库通过 GitHub Pages 公开发布，请勿提交不希望公开的私人记录。
